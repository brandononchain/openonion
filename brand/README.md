# OpenOnion brand kit

The mark is an onion whose layers **spiral open** around a warm amber core. It stands for an agent with nothing
hidden inside: open source, transparent, liberated.

## Colors

| Name | Hex | Use |
|---|---|---|
| Deep Indigo | `#2b1b6b` | Outer layer, dark backgrounds |
| Night | `#120e17` | Dark UI / banner background |
| Violet | `#7b3fe4` | Middle layer, gradients |
| Brand Violet | `#6b3fa0` | "Onion" in the wordmark, UI accent |
| Lavender | `#d9ccff` | Inner layer, text on dark |
| Amber Core | `#ffb347` | The core. Use sparingly; it's the focal point |
| Charcoal | `#1d1a22` | "Open" in the wordmark, body text |

Wordmark: **OpenOnion**, one word with two capitals, in a geometric sans (Montserrat / Poppins / Manrope are close matches).
"Open" is charcoal (or white on dark) and "Onion" is violet.

## Rules

- Keep clear space around the mark equal to the diameter of the amber core.
- Use the flat mark (not the master) below 32 px; the gradient version muddies at small sizes.
- Keep the spiral and the amber core. **Don't** redraw it as concentric rings or a plain purple bulb, and don't add a
  green sprout: those moves push it toward the Tor Project / Onion Browser marks, which we deliberately avoid.
- Don't recolor the core, stretch the mark, or place the gradient tile on busy photos.
> Full-resolution masters (2048 px icons, 2688 px banners and hero) ship in the separate brand-kit download.
